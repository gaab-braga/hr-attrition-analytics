📚 Metodologia

Regressão Logística

Modelo interpretável para identificar drivers de turnover. Odds Ratios indicam o aumento proporcional no risco. Validação cruzada (5-fold) para robustez. Intervalos de confiança via matriz de Fisher.

Análise de Sobrevivência

Kaplan-Meier para estimar curvas de retenção. Hazard rates identificam períodos críticos. Teste Log-Rank compara grupos. Greenwood para intervalos de confiança.

Clustering K-Means

Segmentação não-supervisionada de colaboradores. Silhouette Score para validação. Features normalizadas (Z-score). Perfis gerados automaticamente.
